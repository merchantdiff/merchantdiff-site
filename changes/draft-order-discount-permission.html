November 18, 2026 Action / breaking change

`draftOrderCreate` and `draftOrderUpdate` require the `apply_discounts_to_draft_orders` permission to add discounts

Action RequiredAPIBreaking API ChangeGraphQL Admin API2026-01

Shopify developer change

MerchantDiff detected this entry in Shopify's official developer changelog on November 18, 2026.

This Shopify update is categorized as Action Required, API, Breaking API Change, GraphQL Admin API, 2026-01.

What changed

When a request runs as a staff member who doesn't have the apply_discounts_to_draft_orders permission, draftOrderCreate and draftOrderUpdate reject any change that adds discounts through the DraftOrderInput: Adding a discount code to discountCodes that the draft order doesn't already have. Setting acceptAutomaticDiscounts to true on a draft order that doesn't already accept automatic discounts. For draftOrderCreate, any non-empty discountCodes or acceptAutomaticDiscounts: true counts as adding a discount because the draft order doesn't exist yet. In these cases, the mutation returns null for draftOrder and a user error on each field that adds a discount: discountCodes or acceptAutomaticDiscounts. For draftOrderUpdate, the field path starts with input.

Who is affected

Apps that do all of the following are affected: Calls draftOrderCreate or draftOrderUpdate as a staff member. Expects to add discount codes or enable automatic discounts. Doesn't ensure that the staff member has the apply_discounts_to_draft_orders permission.

What action may be needed

Check userErrors on draftOrderCreate and draftOrderUpdate for an error on discountCodes or acceptAutomaticDiscounts. If your app needs to add discounts, ask the merchant to give the staff member the Apply discounts permission under Draft orders.
