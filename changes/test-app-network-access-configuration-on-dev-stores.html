Test app network access configuration on dev stores

PlatformUpdate

Shopify developer change

MerchantDiff detected this entry in Shopify's official developer changelog on November 04, 2026.

This Shopify update is categorized as Platform, Update.

What changed

When you create a dev store with the network_access_testing feature preview, you can confirm your network configuration behaves as expected: Links to hosts that aren't in allowed_navigation_hosts show the exit warning, so you can ensure you're warning when appropriate and not showing exit warnings for trusted hosts. The browser console warns when a storefront page loads from or sends requests to a server that isn't in allowed_sources. The preview only warns. It doesn't block anything.

Who is affected

Any app whose code links to or contacts external servers from a storefront can use this new testing option. Shopify recommends all apps configure these settings to avoid navigation warnings on merchant sites, and to help Shopify spot suspicious activity.

What action may be needed

For step-by-step instructions and troubleshooting, follow the steps to test network access configuration on a dev store.
