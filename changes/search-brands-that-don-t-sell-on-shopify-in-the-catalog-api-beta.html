Search brands that don't sell on Shopify in the Catalog API (beta)

CatalogUpdate

Shopify developer change

MerchantDiff detected this entry in Shopify's official developer changelog on October 27, 2026.

This Shopify update is categorized as Catalog, Update.

What changed

The Catalog API beta now supports a sources parameter on search_catalog that controls which products you return: Shopify merchant products only: omit sources, or set ["shopify"] Both Shopify merchant and external products: ["shopify", "external"] Brands that don't sell on Shopify only: ["external"] The sources parameter works on the existing search_catalog method, with no new endpoint to call. The get_product method returns an external product when you pass its ID, and lookup_catalog support is coming later. External products always return eligible.native_checkout: false, so shoppers can't buy them through Shopify checkout and these products don't earn Promoted Placements commission. Each external product includes a description, an image, a price, and a link to the brand's product page so the shopper completes the purchase on the brand's own site.

Who is affected

This change affects apps that use the Catalog API to power on-site search or recommendations and want to include products from brands that don't sell on Shopify. During the beta, external product data comes from each brand's website, and external products only return when the shopper is in the United States. Searches for shoppers in other countries continue to return Shopify merchant products only.

What action may be needed

No action is required if you only want to keep returning products from Shopify merchants. Your existing search_catalog calls work without changes. If you want to include external products, update your search_catalog requests to set the sources parameter to ["shopify", "external"], or to ["external"] if you only want brands that don't sell on Shopify.
