Sidekick can now invoke app intents without tools

PlatformUpdate

Shopify developer change

MerchantDiff detected this entry in Shopify's official developer changelog on September 28, 2026.

This Shopify update is categorized as Platform, Update.

What changed

An extension is Sidekick-eligible when it declares tools, intents, or both. Before this change, only tools counted. Nothing about the configuration format changed: the [[extensions.targeting.intents]] block you already declare for app actions is now enough on its own, on both the admin.app.intent.link and admin.app.intent.render targets.

Who is affected

You're affected if your app has at least one extension that declares intents without tools. Those extensions become visible to Sidekick immediately, and if your shopify.app.toml has no extensions_summary, your next deploy fails with a validation error naming the missing field. You're not affected if every Sidekick extension in your app already declares tools.

What action may be needed

Most apps need no change. If you have an intent-only extension, do this before your next deploy: Check each shopify.extension.toml for a [[extensions.targeting.intents]] block on admin.app.intent.link or admin.app.intent.render with no tools file alongside it. If you find one, confirm your shopify.app.toml has an extensions_summary under [sidekick]. Add one if it's missing.
