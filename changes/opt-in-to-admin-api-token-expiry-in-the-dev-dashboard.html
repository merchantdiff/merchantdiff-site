Declare that your app uses only expiring Admin API tokens

Dev DashboardNew

Shopify developer change

MerchantDiff detected this entry in Shopify's official developer changelog on November 16, 2026.

This Shopify update is categorized as Dev Dashboard, New.

What changed

When you enable Admin API token expiry for an app, it applies across every store where that app is installed. GraphQL and REST Admin API requests then fail if they use either: A non‑expiring offline access token A delegate access token with more than 24 hours remaining before expiry Enforcement can take up to 30 minutes to take effect. Enabling the setting doesn’t migrate or revoke existing tokens. You can turn the setting off if you encounter issues. Turning it off doesn’t change the April 1, 2027 enforcement deadline for public apps or the December 1, 2026 requirement for custom apps.

Who is affected

This setting is available for all app types in the Dev Dashboard. It affects an app only after you turn it on for that app. Expiring tokens are required for all apps: **December 1, 2026: ** Custom apps created on or after must use expiring tokens.

What action may be needed

We recommend turning on Admin API token expiry to give you peace of mind that your migration is complete ahead of the deadlines. Complete your migration using the Admin API token expiry migration guide, then review your app’s GraphQL and REST logs for affected requests. The Dev Dashboard highlights potential token‑expiry issues detected in the last 14 days, though detection can lag by a day. Open your app in the Dev Dashboard, go to Settings, and select Turn on in the Admin API token expiry card.
